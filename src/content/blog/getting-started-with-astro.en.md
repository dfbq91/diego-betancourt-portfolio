# Getting started with Astro

Astro is a modern web framework that revolutionizes how we build websites. Its "Island" architecture allows sending JavaScript only when needed, resulting in incredibly fast sites.

## Why Astro?

1. **Exceptional performance**: Zero JavaScript by default
2. **Flexibility**: Supports React, Vue, Svelte and more
3. **Developer experience**: Fast Hot Module Replacement
4. **Content Collections**: Typed content management

## Installation

```bash
npm create astro@latest
```

## Basic structure

```
src/
├── components/
├── layouts/
├── pages/
└── content/
```

## Conclusion

Astro is ideal for static sites, blogs, and applications where performance is critical. Try it on your next project.
