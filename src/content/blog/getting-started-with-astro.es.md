# Primeros pasos con Astro

Astro es un framework web moderno que revoluciona la forma en que construimos sitios web. Su arquitectura "Island" permite enviar JavaScript solo cuando es necesario, resultando en sitios increíblemente rápidos.

## ¿Por qué Astro?

1. **Rendimiento excepcional**: Zero JavaScript por defecto
2. **Flexibilidad**: Soporta React, Vue, Svelte y más
3. **Developer experience**: Hot Module Replacement rápido
4. **Content Collections**: Gestión tipada de contenido

## Instalación

```bash
npm create astro@latest
```

## Estructura básica

```
src/
├── components/
├── layouts/
├── pages/
└── content/
```

## Conclusión

Astro es ideal para sitios estáticos, blogs y aplicaciones donde el rendimiento es crítico. Pruébalo en tu próximo proyecto.
