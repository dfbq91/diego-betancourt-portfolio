# Diego Betancourt — Documento fuente del chat

Este documento es la única fuente de verdad que el chat ("Chatea con Diego") usa para responder preguntas sobre Diego: quién es, su trayectoria profesional y su vida personal. Cada vez que se actualiza este archivo y se redespliega el sitio, el índice de respuestas se regenera automáticamente.

## Quién es Diego

Diego Betancourt es un desarrollador de software colombiano con más de 5 años de experiencia en desarrollo full-stack. Vive en Colombia y trabaja actualmente como Senior Software Engineer en Tech Solutions SAS. Se define como alguien apasionado por resolver problemas complejos con soluciones elegantes, y cree firmemente en escribir código limpio, testeable y bien documentado.

Su especialidad es crear aplicaciones web modernas, escalables y con excelente experiencia de usuario. Le motiva construir productos que la gente use de verdad, no solo código que funcione.

## Vida personal

Cuando no está programando, a Diego le gusta contribuir a proyectos open source y compartir conocimiento con la comunidad de desarrollo. Disfruta escribir artículos técnicos en su blog sobre temas como desarrollo web moderno, CSS y frameworks como Astro.

Diego valora el equilibrio entre trabajo y vida personal. Es de las personas que prefieren una buena conversación sobre tecnología y diseño antes que una reunión sin propósito. Su curiosidad por aprender lo lleva a estar siempre explorando herramientas nuevas, aunque sea escéptico de las modas pasajeras del mundo tech.

## Trayectoria profesional

Diego empezó su carrera como Junior Developer en StartupHub (junio 2019 – diciembre 2019), donde participó en el desarrollo de MVPs para múltiples startups, creó APIs RESTful documentadas con Swagger y colaboró en equipos ágiles con metodologías Scrum.

Luego trabajó como Full Stack Developer en Digital Innovation Labs (enero 2020 – febrero 2022). Allí desarrolló aplicaciones web responsivas con React y Node.js, optimizó consultas de base de datos reduciendo tiempos de respuesta en un 75%, e implementó un pipeline de CI/CD que redujo el tiempo de despliegue de horas a minutos.

Desde marzo de 2022 es Senior Software Engineer en Tech Solutions SAS. Lideró el desarrollo de una plataforma de comercio electrónico que aumentó las ventas en un 40%, implementó una arquitectura de microservicios que redujo los tiempos de carga en un 60%, y mentorizó a 3 desarrolladores junior mejorando la calidad del código del equipo.

## Proyectos destacados

TaskMaster Pro es una aplicación de gestión de tareas en tiempo real con colaboración en equipo, notificaciones push y sincronización offline, construida con React, Node.js, PostgreSQL y WebSocket.

WeatherDash es un dashboard meteorológico con visualizaciones interactivas, alertas personalizadas y datos históricos de más de 10 años, construido con Vue.js, D3.js, Python y FastAPI.

DevPortfolio es un generador de portafolios para desarrolladores con múltiples templates, integración con GitHub y hosting estático, construido con Astro, TypeScript y Tailwind CSS.

Este mismo sitio web es otro de sus proyectos: lo construyó con Astro y Tailwind CSS, aplicando un flujo de desarrollo guiado por especificaciones (spec-driven development), con tests end-to-end y despliegue en Cloudflare.

## Filosofía de trabajo

Diego prefiere soluciones simples sobre soluciones inteligentes: si algo se puede resolver con menos código y menos dependencias, esa es la ruta. Le gusta trabajar en equipos pequeños donde la comunicación es directa y el feedback es honesto.

Cree que la documentación y los tests no son opcionales, sino parte del producto. Por eso este portfolio tiene especificaciones versionadas en el repositorio y pruebas automatizadas que validan cada página.
