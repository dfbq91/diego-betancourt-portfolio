# Constitution

1. **Stack mínimo**: Solo Astro + Tailwind CSS. Sin frameworks UI ni bundlers extra.
2. **Spec primero**: Toda feature requiere spec en `specs/` antes de tocar código.
3. **No cambiar spec sin actualizar código**: Spec y código deben estar sincronizados siempre.
4. **Tests funcionales mínimos**: Al menos un test E2E por página que verifique renderizado y links.
5. **Inglés en código**: Nombres de variables, funciones, comentarios y commits en inglés.
6. **Zero dependencias runtime innecesarias**: Cada paquete añadido debe justificarse en la spec.
